# 開發筆記 (Dev Notes)

## 分析任務類型 (Analysis Task Types)

目前系統支援 7 種資料分析任務類型，以下為其名稱與內容說明：

1. **`descriptive` (敘述性統計)**
   - **內容**：針對數值欄位計算基本的統計量，例如：平均數 (Mean)、中位數 (Median)、標準差 (Standard Deviation)、最大值與最小值等，用來快速了解資料的基本輪廓。

2. **`correlation` (相關性分析)**
   - **內容**：計算數值欄位之間的相關係數矩陣 (Correlation Matrix)，幫助找出哪些變數之間具有高度的正相關或負相關。

3. **`descriptive_with_correlation` (敘述性統計與相關性)**
   - **內容**：將上述「敘述性統計」與「相關性分析」合併在一起執行的綜合性任務。這是目前系統預設在資料集上傳後自動觸發的基礎分析。

4. **`group_by` (分組聚合分析)**
   - **內容**：類似 SQL 中的 `GROUP BY` 功能，選擇一個維度欄位（例如：地區、產品類別），並將其他數值欄位根據該維度進行聚合計算（例如：加總、平均數、計數）。

5. **`time_series` (時間序列分析)**
   - **內容**：針對具有時間屬性的資料，進行不同時間維度（如：日、週、月、年）的聚合與趨勢分析，用來觀察指標隨時間變化的情況。

6. **`distribution` (數據分佈分析)**
   - **內容**：用來分析單一變數的分布狀況。對於數值型資料可以查看直方圖 (Histogram) 或密度分佈；對於類別型資料則可以查看各類別的次數或頻率分配。

7. **`cross_tabulation` (交叉樞紐分析)**
   - **內容**：類似 Excel 的樞紐分析表 (Pivot Table) 或交叉表 (Cross-tab)，選擇列 (Index) 與行 (Columns) 的變數，並可指定聚合方式，用來分析兩個類別變數之間的關聯或數值分佈。
